Clé d'accès

Cette page lit vos statistiques Umami. Elle a besoin de votre clé API, à créer une seule fois dans Umami : menu de votre compte, puis Profile ou Settings, section API keys.

La clé est enregistrée uniquement dans ce navigateur et n'est jamais envoyée ailleurs qu'à Umami. Elle ne figure pas dans le code du site, donc personne d'autre ne peut lire vos chiffres en ouvrant cette page.
